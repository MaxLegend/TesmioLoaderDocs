# Начало работы

Добро пожаловать в **Markdown Viewer** — лёгкий статичный сайт для отображения документации в формате Markdown с красивым адаптивным интерфейсом.

Этот просмотрщик читает `.md` файлы из папки `guide/` и автоматически строит навигацию в боковом меню слева. Локализованные варианты (например, `00-getting-started.md` и `00-getting-started_RU.md`) группируются вместе под одним элементом навигации, а переключатель языка отображается как в боковом меню, так и вверху документа.

## Основные возможности

- **Динамическая навигация** — Боковое меню строится автоматически на основе файлов в `guide/`. Никакой ручной настройки не требуется.
- **Поддержка локализации** — Файлы с суффиксом `_XX` (например, `_RU`, `_ES`) группируются как переводы одного документа.
- **Светлая и тёмная темы** — Кнопка переключения темы в шапке позволяет читателям мгновенно переключаться. Выбор сохраняется в `localStorage`.
- **Поиск** — Фильтрация документов в боковом меню по названию или slug.
- **Подсветка кода** — На базе `highlight.js` с темой GitHub.
- **GitHub Flavored Markdown** — Таблицы, списки задач, зачёркивание и многое другое поддерживается через `marked.js`.
- **Deep linking** — У каждого документа свой URL-хеш (например, `#/getting-started`), что упрощает обмен ссылками.
- **Адаптивность** — На маленьких экранах боковое меню превращается в выезжающую панель.
- **Без сборки** — Чистые HTML/CSS/JS. Просто опубликуйте на GitHub и включите Pages.

## Быстрый старт

1. **Склонируйте или скачайте** этот проект.
2. **Добавьте ваши `.md` файлы** в папку `guide/`.
3. **Опубликуйте на GitHub** и включите GitHub Pages в настройках репозитория.
4. **Готово!** Ваш сайт документации работает.

::: tip
Вы можете переключить язык интерфейса на английский с помощью кнопки `EN` вверху этой страницы или в боковом меню.
:::

## Соглашение об именовании файлов

| Файл | Порядок | Slug | Язык |
|------|---------|------|------|
| `00-getting-started.md` | 0 | `getting-started` | По умолчанию (EN) |
| `00-getting-started_RU.md` | 0 | `getting-started` | Русский |
| `01-installation.md` | 1 | `installation` | По умолчанию (EN) |
| `01-installation_RU.md` | 1 | `installation` | Русский |
| `99-faq.md` | 99 | `faq` | По умолчанию (EN) |

Числовой префикс (`00-`, `01-`, ...) управляет порядком сортировки в боковом меню. Файлы без префикса сортируются последними.
