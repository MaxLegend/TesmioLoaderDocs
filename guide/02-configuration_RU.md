# Конфигурация

Просмотрщик можно настроить, отредактировав объект `CONFIG` в начале файла `js/app.js`.

## Параметры конфигурации

```javascript
const CONFIG = {
    // Путь к папке с .md файлами (относительно корня сайта)
    guidePath: './guide',

    // Имя файла-манифеста (fallback если GitHub API недоступен)
    manifestFile: 'manifest.json',

    // Язык интерфейса по умолчанию
    defaultLang: 'RU',

    // Метка для файлов без языкового суффикса
    defaultLangLabel: 'EN',

    // Настройки GitHub API (авто-определение по URL)
    github: {
        owner: null,
        repo: null,
        branch: 'main',
    },
};
```

## Описание параметров

### `guidePath`
Путь к папке с документацией относительно корня сайта. Используйте `./guide` для папки `guide/` на том же уровне, что и `index.html`.

### `manifestFile`
Имя JSON-файла манифеста, используемого как запасной вариант. Файл должен находиться внутри `guidePath` и содержать JSON-массив имён файлов:

```json
["file1.md", "file2.md", "file3_RU.md"]
```

### `defaultLang`
Код языка, который будет выбран по умолчанию при загрузке просмотрщика. Установите его на язык, который использует большинство ваших читателей.

### `defaultLangLabel`
Метка, отображаемая в переключателе языка для файлов без суффикса `_XX`. Например, если ваши «дефолтные» файлы на английском, установите `EN`.

### `github.branch`
Имя ветки для запросов к GitHub Contents API. По умолчанию `main`. Если ваш репозиторий использует `master`, измените на `'master'`.

## Настройка интерфейса

### Изменение логотипа и заголовка

Отредактируйте span `.logo-text` в `index.html`:

```html
<a href="#" class="logo" id="logo">
    <!-- SVG иконка -->
    <span class="logo-text">Моя документация</span>
</a>
```

### Изменение цветов

Все цвета определены как CSS-переменные в `css/styles.css`. Чтобы изменить акцентный цвет:

```css
:root {
    --accent: #0969da;        /* Основной акцент */
    --accent-hover: #0550ae;  /* При наведении */
    --accent-bg: #ddf4ff;     /* Светлый фон */
}
```

### Изменение ширины бокового меню

```css
:root {
    --sidebar-width: 280px;  /* По умолчанию: 280px */
}
```

### Изменение ширины контента

```css
:root {
    --content-max-width: 820px;  /* По умолчанию: 820px */
}
```

## Правила именования файлов

Просмотрщик парсит имена файлов по следующему шаблону:

```
[NN-]slug[_XX].md
```

Где:
- `NN-` — необязательный числовой префикс для сортировки (например, `00-`, `01-`, `99-`)
- `slug` — идентификатор документа (например, `getting-started`)
- `_XX` — необязательный двухбуквенный код языка (например, `_RU`, `_ES`, `_DE`)

### Примеры

| Имя файла | Порядок | Slug | Язык |
|-----------|---------|------|------|
| `intro.md` | 9999 | `intro` | По умолчанию |
| `intro_RU.md` | 9999 | `intro` | Русский |
| `00-intro.md` | 0 | `intro` | По умолчанию |
| `00-intro_RU.md` | 0 | `intro` | Русский |
| `10-advanced/api.md` | 10 | `advanced/api` | По умолчанию |
| `10-advanced/api_RU.md` | 10 | `advanced/api` | Русский |

::: tip
Файлы с `/` в slug автоматически группируются под заголовком секции в боковом меню. Имя секции берётся из первой части пути.
:::

## Добавление нового языка

1. Создайте новый файл с соответствующим суффиксом, например `00-getting-started_ES.md`.
2. (Необязательно) Добавьте метку языка в функцию `getLangLabel` в `app.js`:

```javascript
const labels = {
    // ...существующие метки...
    'ES': 'Español',
};
```

3. Отправьте на GitHub. Новый язык автоматически появится в переключателе.
