# Установка

Это руководство проведёт вас через процесс развёртывания Markdown Viewer на GitHub Pages всего за несколько минут.

## Предварительные требования

- Аккаунт [GitHub](https://github.com) (подойдёт бесплатный).
- Установленный Git на вашем компьютере.
- Ваша документация в формате `.md`.

## Шаг 1 — Создание репозитория

1. Перейдите на [github.com/new](https://github.com/new).
2. Назовите репозиторий (например, `my-docs`).
3. Установите видимость **Public** (Pages на бесплатных аккаунтах требует публичных репозиториев).
4. Отметьте **Add a README file**.
5. Нажмите **Create repository**.

## Шаг 2 — Загрузка файлов просмотрщика

Склонируйте репозиторий на компьютер:

```bash
git clone https://github.com/YOUR_USERNAME/my-docs.git
cd my-docs
```

Скопируйте следующие файлы из этого проекта в корень репозитория:

```
index.html
css/
  styles.css
js/
  app.js
guide/
  *.md  (ваша документация)
  manifest.json
```

Закоммитьте и отправьте:

```bash
git add .
git commit -m "Add markdown viewer"
git push origin main
```

::: warning
Если ваша ветка по умолчанию называется `master`, а не `main`, обновите значение `CONFIG.github.branch` в файле `js/app.js`.
:::

## Шаг 3 — Включение GitHub Pages

1. Откройте ваш репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Source** выберите **Deploy from a branch**.
4. Выберите вашу ветку (`main` или `master`) и папку `/ (root)`.
5. Нажмите **Save**.

Подождите 1–2 минуты, затем обновите страницу. Ваш сайт будет доступен по адресу:

```
https://YOUR_USERNAME.github.io/my-docs/
```

## Шаг 4 — Добавление документации

Поместите любой `.md` файл в папку `guide/` и отправьте изменения. Навигация обновится автоматически при следующей загрузке страницы.

::: tip
Вам не нужно обновлять `manifest.json` каждый раз при добавлении файла — просмотрщик использует GitHub API для получения содержимого папки. Манифест используется только как запасной вариант, когда API недоступен из-за лимитов.
:::

## Локальная разработка

Вы можете просмотреть сайт локально с помощью любого статического файлового сервера:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server -p 8000

# PHP
php -S localhost:8000
```

Затем откройте [http://localhost:8000](http://localhost:8000) в браузере.

::: warning
Если вы откроете `index.html` напрямую через `file://`, некоторые браузеры заблокируют `fetch()` запросы. Всегда используйте локальный сервер.
:::

## Обновление манифеста

Файл `manifest.json` — это запасной вариант, используемый когда GitHub API недоступен. Чтобы перегенерировать его после добавления новых файлов:

```bash
# Из папки guide/
ls *.md | jq -R . | jq -s . > manifest.json
```

Или отредактируйте вручную — это просто JSON-массив имён файлов:

```json
[
  "00-getting-started.md",
  "00-getting-started_RU.md",
  "01-installation.md"
]
```

## Решение проблем

| Проблема | Решение |
|----------|---------|
| Навигация показывает «Документация не найдена» | Проверьте, что папка `guide/` существует и содержит `.md` файлы. Также проверьте `manifest.json`, если GitHub API недоступен из-за лимитов. |
| 404 при загрузке документа | Убедитесь, что путь к файлу в `guide/` соответствует записи в манифесте. |
| Код не подсвечивается | Проверьте консоль браузера на ошибки загрузки `highlight.js`. |
| Тема не сохраняется | Убедитесь, что `localStorage` включён в вашем браузере. |
