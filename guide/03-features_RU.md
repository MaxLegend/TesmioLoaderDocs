# Возможности Markdown

Эта страница демонстрирует все возможности Markdown, поддерживаемые просмотрщиком.

## Заголовки

```markdown
# Заголовок H1
## Заголовок H2
### Заголовок H3
#### Заголовок H4
##### Заголовок H5
###### Заголовок H6
```

Наведите курсор на любой заголовок, чтобы увидеть якорную ссылку (🔗) для удобного обмена.

## Форматирование текста

- **Жирный текст** через `**двойные звёздочки**` или `__двойные подчёркивания__`
- *Курсив* через `*одинарные звёздочки*` или `_одинарные подчёркивания_`
- ***Жирный курсив*** через `***тройные звёздочки***`
- ~~Зачёркнутый~~ через `~~двойные тильды~~`
- `Инлайн-код` через обратные кавычки

## Цитаты

```markdown
>

```

>
> > Вложенные цитаты также поддерживаются.

## Списки

### Маркированные списки

```markdown
- Элемент 1
- Элемент 2
  - Вложенный элемент 2.1
  - Вложенный элемент 2.2
- Элемент 3
```

- Элемент 1
- Элемент 2
  - Вложенный элемент 2.1
  - Вложенный элемент 2.2
- Элемент 3

### Нумерованные списки

```markdown
1. Первый элемент
2. Второй элемент
3. Третий элемент
   1. Вложенный нумерованный
   2. Ещё один вложенный
```

1. Первый элемент
2. Второй элемент
3. Третий элемент
   1. Вложенный нумерованный
   2. Ещё один вложенный

### Списки задач

```markdown
- [x] Выполненная задача
- [ ] Ожидающая задача
- [ ] Ещё одна ожидающая задача
```

- [x] Выполненная задача
- [ ] Ожидающая задача
- [ ] Ещё одна ожидающая задача

## Блоки кода

### Инлайн-код

Используйте обратные кавычки для `инлайн-кода`.

### Блоки кода с ограждением

```javascript
// Пример JavaScript кода
function fibonacci(n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

console.log(fibonacci(10)); // 55
```

```python
# Пример Python кода
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(10))  # 55
```

```bash
# Пример bash скрипта
#!/bin/bash
echo "Привет, мир!"

for i in {1..5}; do
    echo "Итерация $i"
done
```


## Уведомления (кастомный синтаксис)

Просмотрщик поддерживает кастомные блоки-уведомления через синтаксис `:::`:

### Подсказка

```markdown
::: tip
Это полезная подсказка.
:::
```

::: tip
Это полезная подсказка. Используйте её для выделения полезной информации или сокращений.
:::

### Предупреждение

```markdown
::: warning
Это предупреждение. Будьте осторожны!
:::
```

::: warning
Это предупреждение. Используйте его, чтобы предупредить читателей о потенциальных подводных камнях или важных аспектах.
:::

### Опасность

```markdown
::: danger
Это уведомление об опасности. Обратите внимание!
:::
```

::: danger
Это уведомление об опасности. Используйте его, чтобы предупредить о критических проблемах, которые могут привести к потере данных или проблемам с безопасностью.
:::

### Заметка

```markdown
::: note
Это заметка.
:::
```

::: note
Это заметка. Используйте её для дополнительного контекста, который не вписывается в основной поток.
:::

## YAML Front Matter

Просмотрщик автоматически удаляет YAML front matter из начала `.md` файлов:

```markdown
---
title: Мой документ
author: Иван Иванов
date: 2024-01-15
---

# Мой документ

Здесь начинается контент.
```

Если в front matter присутствует поле `title`, оно используется как заголовок документа в боковом меню.

## Поддержка HTML

Сырой HTML поддерживается внутри Markdown (и очищается через DOMPurify для безопасности):

```markdown
<details>
<summary>Нажмите для раскрытия</summary>

Скрытый контент находится здесь.

</details>
```

<details>
<summary>Нажмите для раскрытия</summary>

Скрытый контент находится здесь. Это полезно для сворачиваемых секций.

</details>

## Эмодзи

GitHub-стиль коротких кодов эмодзи НЕ поддерживается по умолчанию (просмотрщик использует стандартный `marked.js` без плагина эмодзи). Используйте Unicode-эмодзи напрямую:

✅ ❌ ⚠️ 💡 📝 🔥 🚀 📚
